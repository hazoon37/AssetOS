# Sprint 3 — Unified Portfolio Workspace

> 상태: 역사적 구현 기록. 현재 탐색과 UX 규칙은 `Product_Vision.md`와
> `UX_RULES.md`를 우선합니다.

## 목적

보유자산 관리와 포트폴리오 분석을 하나의 사용자 흐름으로 통합한다.

## 최종 사용자 메뉴

1. 대시보드: 전체 자산 핵심 요약
2. 포트폴리오: 등록·수정·삭제·구성·위험·보고서
3. 종목분석: 개별 투자대상의 투자 가치 분석

자산관리는 네 번째 페이지가 아니다. 대시보드의 `➕ 자산관리` dialog와
포트폴리오의 보유자산 탭은 등록·수정·삭제, 검색, 일괄 삭제, 내보내기와
Smart Import 컴포넌트를 공유한다. 두 화면은 동일한 저장 서비스와 컴포넌트를
사용한다. Smart Import의 동작 규칙은 `SMART_IMPORT_SPEC.md`를 따른다.

## 포트폴리오 탭

- 보유자산: 신규 등록, 검색, 수정, 삭제, 상세표
- 구성 분석: 자산군, 국가, 통화, 섹터, 자산별 비중
- 위험 분석: Portfolio Score, 집중도, 스트레스 테스트, Investment DNA
- 보고서: 구조 요약, 핵심 해석, 주요 위험, 운용 점검 원칙

## 데이터 갱신

자산 등록·수정·삭제 시 포트폴리오 분석 캐시를 즉시 초기화한다.
