# Sprint 2 — Portfolio Intelligence v1

## 추가 기능
- 100점 기준 Portfolio Score
- 분산, 현금 유연성, 레버리지 관리, 국가·통화 분산의 세부 점수
- 4개 간이 스트레스 시나리오
- 태그·섹터 기반 Investment DNA
- 구조적 강점과 위험의 자동 요약

## 해석 주의
점수와 스트레스 테스트는 수익률 예측이나 매매 신호가 아니다. 현재 보유구조의 집중도와 위험 민감도를 빠르게 확인하기 위한 규칙 기반 진단이다.
