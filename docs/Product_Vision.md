# AssetOS Product Vision

## Dashboard first

AssetOS의 첫 화면은 대시보드다. 사용자는 앱을 열자마자 총자산, 투자원금,
손익, 수익률, 자산 배분과 주요 변화를 빠르게 파악할 수 있어야 한다.

대시보드는 의사결정에 필요한 핵심 정보부터 보여준다. 데이터가 없거나 계산할
수 없는 값은 `0`으로 추정하지 않고 `정보 없음` 또는 `계산 불가`로 표시한다.

## 3-page philosophy

사용자 메뉴는 세 가지 핵심 흐름에 집중한다.

1. **대시보드** — 전체 자산의 현재 상태를 한눈에 확인한다.
2. **포트폴리오** — 보유 구조, 배분, 위험과 보고서를 분석한다.
3. **종목분석** — 개별 투자대상의 투자 정보를 깊이 살펴본다.

## ➕ 자산관리

자산관리는 별도 탐색 목적지가 아니라 대시보드에서 시작하는 작업이다.
사용자는 `➕ 자산관리`를 통해 템플릿 다운로드, 내보내기와 가져오기에
빠르게 접근한다.

대시보드의 자산관리는 빠른 진입점이며, 포트폴리오의 보유자산 탭은 상세
등록·수정·삭제와 검토를 담당한다. 두 진입점은 같은 서비스와 컴포넌트를
사용하며 서로 다른 저장 로직을 만들지 않는다.

## Smart Import

Smart Import는 최소 입력을 검증·해석·보강한 뒤 사용자 확인을 거쳐 자산
데이터로 반영하는 제품 기능이다. 입력 계약, Asset Resolver, 후보 선택,
가격, fallback, 검증, 적용과 호환성에 관한 모든 규칙은
[`SMART_IMPORT_SPEC.md`](SMART_IMPORT_SPEC.md)를 따른다.

## Input minimum, analysis maximum

AssetOS의 제품 원칙은 **입력은 최소화하고 분석은 극대화하는 것**이다.
Smart Import의 구체적인 최소 입력과 자동 해결 규칙은
[`SMART_IMPORT_SPEC.md`](SMART_IMPORT_SPEC.md)에 정의한다. 정리된 데이터는
대시보드, 포트폴리오 분석과 향후 AI 인사이트의 공통 기반이 된다.

## Product principles

1. **Truth before completeness** — 모르는 값을 추정값처럼 저장하거나 표시하지 않는다.
2. **User confirmation before mutation** — 데이터 변경은 영향 확인과 명시적 동의 후 실행한다.
3. **Never guess ambiguity** — 불확실한 대상을 확정된 사실처럼 선택하지 않는다.
4. **Manual input wins** — 사용자가 명시한 유효한 값과 의도를 존중한다.
5. **Reversible by default** — 대량 변경 전 백업하고 실패 시 원본 상태를 유지한다.
6. **Explain data provenance** — 자동조회 출처, 기준 통화, 가격 기준과 갱신 상태를 확인할 수 있어야 한다.
7. **Graceful degradation** — 외부 API 실패가 수동 입력과 기존 자산 조회를 막지 않는다.
8. **One source of truth** — 조회·계산·저장 규칙을 화면마다 복제하지 않는다.
9. **Fast by default** — 첫 화면에서 필요하지 않은 네트워크 조회와 대용량 생성을 지연한다.
10. **Mobile-ready** — 정보 우선순위와 작업 흐름이 작은 화면에서도 유지되어야 한다.
11. **User-owned and private** — 자산 데이터와 API 비밀정보는 사용자가 통제하며, 명시적 기능 수행에 필요한 범위 밖으로 전송하지 않는다.
12. **Backward compatible** — 기존 DB와 표준 Excel 파일은 명시적인 마이그레이션 없이 갑자기 사용할 수 없게 만들지 않는다.
13. **Deterministic calculations** — 같은 원천 데이터와 기준 시점에는 같은 계산 결과를 제공한다.
14. **Confidence is visible** — 자동 해결 결과의 일치 방식, 출처와 불확실성을 숨기지 않는다.
15. **Decision support, not advice** — 점수, 스트레스 테스트와 AI 설명은 투자 권유나 수익 보장이 아니다.

## Analysis integrity

- 현재가는 수량과 함께 현재 평가금액을 계산하는 데 사용한다.
- 평균매입단가가 없으면 현재 평가금액은 계산할 수 있지만 평가손익과 수익률은 계산하지 않는다.
- 일간 기준가가 없으면 오늘의 변동을 계산하지 않는다.
- AI 요약은 원천 데이터와 규칙 기반 분석을 설명해야 하며 매매 신호처럼 표현하지 않는다.

## Data ownership and privacy

- 자산 원본과 백업은 사용자가 관리하는 저장소에 둔다.
- API 키, 계정정보와 비밀값을 Excel 내보내기, 로그, 오류 메시지 또는 AI 입력에 포함하지 않는다.
- 외부 제공자에는 조회에 필요한 이름·티커·통화만 전달한다.
- 원격 AI 기능을 도입할 때는 전송 데이터, 목적과 보존 여부를 사용자에게 먼저 설명한다.
- 내보내기는 이동성과 복구를 위한 기능이며 특정 제공자에 대한 종속을 만들지 않는다.

## Product boundaries

- AssetOS는 자산 현황과 구조를 이해하기 위한 개인 자산관리 도구다.
- 가격과 환율은 지연되거나 제공자별로 다를 수 있으며 주문 체결 가격이 아니다.
- Portfolio Score와 AI Insight는 설명 가능한 참고 정보이며 매수·매도 지시가 아니다.
- 데이터가 불충분한 분석은 결과를 생성하는 대신 필요한 데이터와 이유를 표시한다.
